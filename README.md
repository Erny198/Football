# Telegram Coach Bot 4+1 — v0.2

Telegram-бот для тренеров детской команды 10–14 лет в формате 4+1.

Бот работает как методический коуч, а не как экзаменатор: помогает выбрать фокус, подобрать упражнение, провести предматчевую и послематчевую рефлексию, зафиксировать выводы.

## Что добавлено в v0.2

- Генератор тренировки: `/training`
- Выбор кейса по теме: `/case`
- Раздел стандартов: `/standards`
- Экспорт журнала в Markdown: `/export`
- Расширенные упражнения и кейсы в JSON
- Абстракция хранилища с JSON по умолчанию
- Подготовка под PostgreSQL в будущей версии

## Команды

```text
/start        — главное меню
/principles   — принципы двух режимов
/exercises    — библиотека упражнений
/standards    — стандарты
/training     — генератор тренировки
/case         — выбрать кейс по теме
/pre_match    — цель перед матчем
/post_match   — вывод после матча
/journal      — журнал выводов
/export       — экспорт журнала в Markdown
/help         — справка
```

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# вставьте BOT_TOKEN в .env
python -m bot.main
```

## Railway

1. Залейте проект в GitHub.
2. Создайте Railway project from GitHub repo.
3. В Variables добавьте:
   - `BOT_TOKEN`
   - опционально `ALLOWED_USER_IDS`
4. Railway использует `railway.json`:
   ```bash
   python -m bot.main
   ```

## Важно про методику

Названия `Guardiola-inspired` и `Arteta-inspired` не означают, что бот копирует официальные программы Пепа Гвардиолы или Микеля Артеты. Это два педагогически адаптированных режима:

- **Позиционный контроль**: линии паса, ширина, глубина, третий игрок, вратарь как первый игрок атаки.
- **Структурная интенсивность**: прессинг, компактность, реакция после потери, роли, подбор, страховка.
